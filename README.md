# Animated Login & Registration Form 🚀

A modern and responsive Login & Registration interface built using HTML, CSS, and JavaScript. The project features smooth animations, sliding transitions, floating labels, and an attractive split-screen design that seamlessly switches between Login and Sign-Up forms.

## Features

✨ Animated Login and Registration Forms

✨ Smooth Sliding Transitions

✨ Modern Split-Screen Layout

✨ Floating Input Labels

✨ Interactive Form Validation UI

✨ Stylish Gradient and Curved Shape Effects

✨ Responsive Design

✨ JavaScript-Based Form Switching

✨ Clean and Modern User Experience

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Boxicons
* Google Fonts (Poppins)
